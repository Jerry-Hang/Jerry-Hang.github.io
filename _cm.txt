feat(frontend): rebuild home layout as a portal-style page

上一版只改了设计 token 没动布局骨架，结果首页是个空旷的竖排列表，
和信息密集的门户式布局差得远。这次重做结构：

首页
- 左栏：置顶/最新文章大卡（封面图 + 分类标签胶囊 + 标题 + 简介 + 统计）
- 右栏：作者卡片（头像/昵称/简介/标签胶囊）+ 最新更新列表 + 站内链接
- 下方：其余文章的两列玻璃卡片网格 + 分页条
- 背景：固定大图（assets/banner.jpg）+ 暗色叠层
- body 加 .home-bg 类，只在首页生效；离开首页回落到极光底

文章页
- 同样换用背景图（叠层更重，保证正文对比度）
- 阅读容器统一玻璃化：reader-head / #r-body / toc / foot / related
- 正文、代码块、表格、引用块的配色相应调深

顶栏
- 原来三个视觉体系混在一行：导航玻璃、查看后台青紫渐变、主题按钮又一种
- 统一成同一套玻璃底 + 统一 hover
- 查看后台改为淡蓝玻璃并提高对比度（实测过各宽度计算样式一致，
  原值 alpha .16/.35 在浅色背景区域会发虚）

过程中确认的事实
- blog_ctl build 不生成 index.html，它是读 index.html 当模板再注入文章内容，
  所以改 index.html 不会被覆盖
