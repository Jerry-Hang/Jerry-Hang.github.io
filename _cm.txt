fix(logs,frontend): record real visitor IP, hide local/LAN traffic, tone down light theme

真实访客 IP（这是个大问题）
- 公网流量经 Cloudflare 隧道进来，cloudflared 反连到 127.0.0.1:8090，
  所以 peer 永远是回环 —— 2.8 万条日志全是 127.0.0.1，安全监控形同虚设
- 新增 client_ip()：优先 CF-Connecting-IP，其次 True-Client-IP / X-Real-IP，
  再取 X-Forwarded-For 第一段，最后才回落 peer
- 实测：模拟 CF-Connecting-IP 后能正确记为 203.0.113.45，并识别出 crawler

来源分级 + 默认过滤
- request_logs 新增 scope 列（local / lan / public），带迁移：
  pragma_table_info 检查列是否存在，缺则 ALTER TABLE 补上，
  再用 SQL CASE 回填旧数据（约 2.8 万行）
- 建表默认值用 'unknown' 当哨兵，避免回填条件误伤新插入的行
- query_logs / today_total / category_counts / peak_malicious_hour /
  hourly_distribution / daily_distribution 全部加 scope='public' 过滤
- 结果：后台从 28056 条降到 0 条（迁移后还没有真实公网访客），
  那 525 条 scan 其实全是本机探测，一个真实攻击都没有
