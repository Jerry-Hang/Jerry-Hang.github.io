# 我的第一篇博客

欢迎来到 **Jerry 的赛博博客**！

这是一个使用 Rust 小工具 `blog_ctl` 加原生 HTML / CSS / JS 搭建的**纯静态博客**。没有框架、没有构建链、没有追踪器 —— 只有文字、样式和一点点赛博魔法。

## 为什么写博客

1. 记录成长：日记是最好的时间机器
2. 整理思考：写下来才算真正想清楚
3. 分享快乐：赛博修仙的日常值得被看见

> 人生如逆旅，我亦是行人。 —— 苏轼
