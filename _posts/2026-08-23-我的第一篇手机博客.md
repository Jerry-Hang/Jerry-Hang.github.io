# 我的第一篇手机博客

这一次，博客完全是在**手机上**写出来的。

## 创作环境

简单列一下我的"移动工作台"：

- 手机一台（被窝里电量 34%）
- **Termux** —— Android 上的命令行终端
- `blog_ctl` —— 纯 Rust 写的小工具
- GitHub Pages —— 免费静态托管

## 工作流

我用一条命令就能从写作到上线：

```bash
blog_ctl new "我的新文章"   # 生成文章
blog_ctl build              # 生成前端数据 posts.json
blog_ctl push "发布新文章"  # 一键推送 GitHub
```

## 感受

> 工具的尽头是随手可用。
> 当写博客像发消息一样自然，记录就变成了习惯。
